# פאקמן

משחק קלאסי של אכילת נקודות, עם 15 שלבים: קלאסי, יער, לילה, אש, בוס, להקה, שעון, רפאים, מראה, סיוט, טורבו, בלי כוח, סערה, פנס וגיהנום.
כל שלב שמסיימים פותח את הבא, וכל שלב מהיר יותר ושווה יותר נקודות. בכל ניסיון יש 3 סיבובים,
ולפני כל סיבוב יש ספירה לאחור. שולטים בהחלקה לכל כיוון על המסך. בלובי יש כפתור "התחל לשחק", בחירת שלב, וטבלת השיאים בצד (🏆).
במצב מנהל כל השלבים פתוחים.

## הרצה בדפדפן
    npm run serve        # http://localhost:8080

## בניית APK

### אפשרות א': GitHub Actions (בלי להתקין כלום)
1. העלה את התיקייה ל-repo חדש ב-GitHub (branch בשם `main`).
2. הקובץ `.github/workflows/build-apk.yml` יבנה את ה-APK אוטומטית בכל push.
3. בלשונית Actions בוחרים את הריצה האחרונה, ומורידים את `chomper-apk` מתחתית העמוד.
4. מעבירים את `app-debug.apk` לטלפון ומתקינים (צריך לאשר "התקנה ממקורות לא ידועים").

### אפשרות ב': על המחשב שלך (Android Studio + JDK 21)
    npm install
    npm run android:sync
    cd android && ./gradlew assembleDebug
    # הקובץ: android/app/build/outputs/apk/debug/app-debug.apk

או `npm run android:open` ואז Run מתוך Android Studio.

## משתמשים וטבלת שיאים (Firebase Realtime Database + Authentication)
- כל שחקן נרשם עם שם וקוד של 4 ספרות. השם ייחודי וקבוע.
- עם השם והקוד אפשר להתחבר שוב בטלפון חדש או אחרי מחיקת המשחק. השם, הניקוד והשלבים חוזרים.
- שחקן ותיק בלי קוד רואה בלובי את הכפתור "🔐 שמור את המשתמש שלך עם קוד".
- כל שחקן יכול רק להעלות את הניקוד של עצמו. אי אפשר לגעת בניקוד של אחרים.
- מצב מנהל (☰ > מצב מנהל > קוד): כל השלבים פתוחים. 🗑 מוחק שחקן ומפנה את השם.
  🔁 מעביר שחקן ותיק למכשיר חדש: הניקוד והשלבים נשמרים עד שהוא נרשם שוב עם אותו שם.
- הקוד של המנהל לא שמור בקוד. הוא חלק מהסיסמה של משתמש Firebase בשם `admin@dpackman.app`.

אחרי כל שינוי ב-`database.rules.json` מדביקים אותו בלשונית Rules של Realtime Database.

## חתימה של ה-APK
כל בנייה נחתמת באותו מפתח, ששמור בסוד `ANDROID_KEYSTORE_B64` ב-GitHub
(Settings > Secrets and variables > Actions). ככה עדכון מותקן מעל הגרסה הקודמת והנתונים נשמרים.
מספר הגרסה עולה אוטומטית בכל בנייה. בלי הסוד, הבנייה מזהירה שה-APK לא יותקן מעל הקודם.

## העלאה לגוגל פליי
ה-APK של debug טוב להתקנה ישירה, לא לחנות. בשביל החנות:
Android Studio > Build > Generate Signed App Bundle > `.aab`.
צור keystore ושמור אותו וגם את הסיסמה במקום בטוח. אם תאבד אותו לא תוכל לעדכן את האפליקציה.

- חשבון מפתח בגוגל פליי עולה 25$ חד-פעמי, ודורש גיל 18+ (חשבון של הורה).
- חשבון אישי חדש חייב Closed testing עם 12 בודקים ל-14 ימים רצופים לפני שאפשר לפרסם.
- השם "פאקמן" והדמויות הם סימן מסחרי של Bandai Namco. לשיתוף בין חברים זה בסדר, אבל לפני גוגל פליי חייבים לשנות שם, אחרת האפליקציה תיחסם.
